## 📋 Hackathon Requirements & Submission Checklist

### 1. Mandatory Technical Constraints
- **PayPal Integration:** Must meaningfully use PayPal Developer Platform (Sandbox environment): REST APIs, JS SDK v6, Orders/Payments, Invoicing, Subscriptions, Webhooks, or PayPal MCP Server.
- **AI Integration:** Must incorporate an AI model, LLM, autonomous agent, or AI platform (Claude, OpenAI, Gemini, local models, etc.).
- **Working Prototype:** A design mockup or static prototype **does not qualify**. Judges must be able to test and run the project.

### 2. Submission Artifact Checklist
- [x] **Public Open-Source Repository:** Hosted on GitHub with an open-source license visible in About section (MIT licensed).
- [ ] **Run Instructions / Hosted Demo:** Step-by-step reproducible instructions (`README.md`, Docker, or live URL).
- [ ] **Demo Video:** Strictly **under 3 minutes**, uploaded publicly to YouTube, demonstrating end-to-end functionality on screen.
- [ ] **Text Description:** Comprehensive explanation of architecture, problem statement, tools used, and technical achievements.
- [ ] **Tools Disclosure:** Explicit listing of AI services, models, and PayPal endpoints utilized.

---

## ⚖️ Judging Criteria & Scoring Rubric

Submissions are evaluated in two stages:
1. **Stage 1 (Pass/Fail):** Baseline viability check confirming meaningful PayPal + AI integration, public repo, and working prototype.
2. **Stage 2 (Equally Weighted Criteria):**
   - **Technological Implementation (20%):** Depth and craftsmanship of PayPal Developer Platform and AI integration; code quality and non-trivial execution.
   - **Design (20%):** Complete, cohesive, and intuitive product experience.
   - **Potential Impact (20%):** Clear value proposition solving authentic problems for buyers or merchants.
   - **Innovation/Idea (20%):** Novelty, creative differentiation from existing tools.
   - **Presentation (20%):** Compelling demo video communicating problem, solution, and live software flow.

This project is configured with automated AI agent skills to plan, build, verify, and pitch the hackathon project.

- `hackathon-judging`: Reverse-engineers judging rubrics, scoring allocation, and tie-breaking mechanics.

### 2. Engineering & Principle Skills (`pstack`)
- `setup-pstack`: Configures model reasoning tiers per role.
